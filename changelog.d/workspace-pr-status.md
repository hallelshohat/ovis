### Added
- Each workspace and worktree shows its pull request, as the herdr plugin
  `jmarbutt.spaces-pr-status` reports it: the number and state, checks, review and diff size in
  herdr's colours. It appears on its own line in the sidebar, as a short mark on the workspace's
  agent rows, beside each open checkout in Open worktree, and in the command palette's workspace
  headings and pane rows. A tap opens the pull request on GitHub, and it updates live as the
  plugin reports.
